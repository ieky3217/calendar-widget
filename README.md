# カレンダーウィジェット（Android）

背景透過・サイズ可変のホーム画面用カレンダーウィジェット。外部ライブラリなし（Kotlin＋標準API）。

## できること
- **サイズに応じて表示が自動で切り替わる**（Android 12以降）
  - 2×1・3×1 … 今週1行（曜日＋日付）
  - 4×1 … 今週1行（大きめ文字・年月表示）
  - 2×2〜3×2 … 月カレンダー
  - 4×3 以上 … 月カレンダー（大きめ文字）
- 背景色（黒／グレー／白／紺）と **背景の濃さ 0〜100%**（0%で完全透明＝文字だけ）
- 文字色（白／黒）、今日の丸の色（赤／青／黄／白）
- 週の始まり（日曜／月曜）、日曜・祝日は赤、土曜は青（祝日は振替休日・国民の休日も計算）
- 月表示の「‹ ›」で前月・翌月、年月タップで今月に戻る
- カレンダー部分タップで端末のカレンダーアプリを開く
- 日付が変わると自動更新（省電力方式のため数分遅れることあり）
- ウィジェットごとに別設定可。長押し →「設定」で変更

## APK の作り方

### A. GitHub Actions（PCに開発環境不要）
1. このフォルダを GitHub の新規リポジトリ（Private 可）に push
2. 「Actions」タブ → 「Build APK」が自動実行（手動なら Run workflow）
3. 完了後、ページ下部の Artifacts から `CalendarWidget-apk` をダウンロード → 中の `app-debug.apk` をスマホへ
4. スマホで開いてインストール（「不明なアプリのインストール」を許可）

### B. Android Studio
1. Android Studio で「Open」→ このフォルダを選択（Gradle 同期を待つ）
2. スマホを USB デバッグで接続 → ▶ Run

## 使い方
1. アプリを開いて見た目を調整 → 「保存」→「ホーム画面に追加」
   （またはホーム画面長押し →「ウィジェット」→「カレンダーウィジェット」）
2. 追加後、ウィジェットを長押しして端をドラッグすればリサイズ

## 構成
- `CalendarWidgetProvider.kt` … ウィジェット本体（更新・月送り・日付変更）
- `WidgetRenderer.kt` … サイズ別レイアウトの組み立て・配色
- `SettingsActivity.kt` … 設定画面（ライブプレビュー付き）
- `JpHolidays.kt` … 日本の祝日計算（2019〜2099年）
- `Prefs.kt` … 設定保存
